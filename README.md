  Primer Proyecto en C++
Este fue mi primer proyecto en C++ el propósito fue aprender a manejar errores y hacer un programa que cuando el usuario escriba cosas que nada que ver no se trabe.

  ¿Que tiene?
Tiene lo básico: suma, resta, multiplicación y division asi como tiene un poco mas de funciones como lo son las potencias, porcentajes, raíces cuadradas y cubicas.
cuenta con un historial de operaciones por si se te olvida que operación acabas de hacer.

  ¿Porque este proyecto?
Quiero dejar de ver tutoriales de muchas horas o copiar codigo y mejor empezar a practicar aunque tarde horas resolviendo errores.
